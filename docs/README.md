- [`SOURCE-LAYOUT.md`](./SOURCE-LAYOUT.md) — where each folder of the original drop lives in this repository.

  ([`porting/PLAN.md`](./porting/PLAN.md), [`porting/LOG.md`](./porting/LOG.md)), the analysis reports the port was
  planned from (`porting/analysis/`), the save-game investigation and the earlier machine bootstrap; on this branch also

  `porting/retail/`: the prototype-versus-retail analysis reports and the engine/render patch). They describe the work
  as it went, not the current state.
