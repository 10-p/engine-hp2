# template-engine — the ENGINE package portability delta the HP2 port must replicate

**Key:** `template-engine` · **Written:** 2026-09-26 (re-run; supersedes the 2026-09-25 draft) ·
**Subject:** every change `engine-ut99/Source/Engine` makes relative to Epic `ut99-v400/Engine`, its
rationale, and whether/how it applies to HP2 build 433 `Source/Engine`; plus the GCC/Win32 hazards HP2's
Engine carries on its own, the CMake source list, and the `EngineClasses.h` ↔ `Engine.u` layout check.

> Report was written incrementally across interrupted runs; all sections are now filled.

## 0. Executive summary

- **Size of the delta.** The template edits **36** Epic Engine files and adds none (only `CMakeLists.txt`; it
  deletes `palette.cpp`). About two-thirds of the ~3,000 diff lines are Dreamcast (`PLATFORM_DREAMCAST`/
  `LOW_MEMORY`, SWORD BSP, `Min<INT>`) and are **not** for HP2. What is left falls into five groups: (1) modern
  GCC/clang fixes (for-scope hoists, `CompareHits` forward decl, `DOREP` on a packed `FRotator`, `PUSH_HIT`
  `decltype`, asm removal in `UnRender.h`, `!a==b`); (2) exceptions-off NULL returns in `UGameEngine`
  (`Init`/`LoadMap`/`SetProgress`); (3) correctness fixes that hit HP2 identically (the C++17
  `PriorityActors[n++]` bug — **three** sites in HP2 — the ABrush `bColoredPad`, savegame `FURL`/`MakeDirectory`,
  the tick-floor, MinGW's `WIN32`≠MSVC); (4) host contract (`FLUSHCONFIG`, SDL mouse capture, `?connect`,
  package-version join failure, "Received" log); (5) features (AutoFOV).
- **Classification (§4, §5, row tags counted).** 42 hunk rows APPLY-CLEANLY (HP2 still has Epic's text at the site), 13 NEED
  ADAPTATION (HP2 moved/duplicated the code: UnLevTic ×3, UnDownload, SaveSlotPath, HP2's 0.10 s tick ceiling),
  5 are ALREADY-PRESENT (MAX_NODES, UnActCol hash repair, UnModel/UnPenLev loops), 40 rows (mostly the Dreamcast set) are
  NOT-APPLICABLE, and **one template edit is a regression that must not be copied** (UnTrace `Use[FrontFirst]`).
  AutoFOV applies to HP2's third-person camera as-is (C2 + D14); its viewmodel and HUD-scale parts do not.
- **HP2-own hazards the template never had (§5.G, §8).** 9 extra for-scope sites in 433-only code (one in the
  header `UnModel.h`, blocking every TU), `CompressXA` using a `_WINDOWS`-only variable (breaks all three
  targets), `UViewport::Destroy` never calling `RenDev->Exit()` on GCC (HP2 moved an `#endif`), the `LOADGAME`
  path parsed as a URL on Unix (the Load menu), a NULL-deref order in `Tick`, and a stale `__STATIC_LINK` native
  table missing 29 natives (so: use the template's `IMPLEMENT_FUNCTION`/`STATIC_EXPORT` route).
- **Windows headers / CMake (§9).** Only `winstuff.cpp` includes `<windows.h>` (already excluded, unused);
  `UnTex.cpp`'s DirectDraw/s3tc/palette includes and the s3tc block must become `#if _MSC_VER`; **remove
  `palette.cpp` from the CMake list**. `UnEngineWin.h` is used by no Engine file.
- **`EngineClasses.h` (§10).** Generated by `ucc make` (`UnEdExp.cpp:276-300`); HP2's copy is **exactly** the
  header `Assets/System/Engine.u` was built with (59 native classes: names, order, MSVC offsets and sizes all
  match; parsed from the shipped package). Under GCC/clang two classes shift: **AMover** (the template's 2.32 bug,
  invisible to a size check) and **APlayerStart** (the size check catches it: 996 vs 1000). Fix both with a
  `#ifndef __MINGW32__` 3-byte pad.
- **Verification (§11).** Port the template's 2.32 runtime guard (`engine-ut99 Core/Src/UnClass.cpp:295-302`,
  `:364-385`, quoted) into HP2's **two** native `UStruct` constructors + `Link`, and add the stronger 1,063
  compile-time `offsetof`/`sizeof` asserts generated from the frozen `.u` (Appendix A) — they need no boot and
  catch the tail-padding class of bug the size guard cannot.
- The ordered to-do list is §12; unresolved points with their verification recipe are §13.

**Classification legend** (used in every hunk row):

| Tag | Meaning |
|-----|---------|
| **APPLIES-CLEANLY** | HP2's text at the same site is identical (modulo whitespace) to Epic's; the template hunk drops in |
| **NEEDS-ADAPTATION** | same intent, but the surrounding HP2 code differs; port the idea by hand (row says how) |
| **ALREADY-PRESENT** | HP2's 433 source already contains the fix / the equivalent |
| **NOT-APPLICABLE** | Dreamcast / LOW_MEMORY / UT99-content-specific, or not required on the port's three targets |
| **DO-NOT-PORT** | a template change that is a regression or a bug; HP2 must deliberately NOT copy it |

Port targets are **native Linux i386 (gcc -m32)**, **Emscripten wasm32 (clang)**, **MinGW i686 (gcc)**. On
all three `int32_t` is `int`, so every `Min/Max/Clamp<INT>` edit the template carries (tag DC) is
**not needed** unless HP2 adopts a `typedef int32_t INT` and something else differs; they are harmless if
copied, and the compiler will name any site that genuinely needs one.

## 10. `EngineClasses.h` — generated? matches `Assets/System/Engine.u`?

### 10.1 It is generated (never hand-edit except the one documented pad)
`Source/Engine/Inc/EngineClasses.h:1-4`:
```cpp
/*===========================================================================
    C++ class definitions exported from UnrealScript.
    This is automatically generated by the tools.
    DO NOT modify this manually! Edit the corresponding .uc files instead!
```
The generator is HP2's own `ucc make` (`Source/Editor/Src/UMakeCommandlet.cpp:208-214`: "Autogenerating C++ header:
`..\<Pkg>\Inc\<Pkg>Classes.h`", unless `-NOHEADER`) driving `UnEdExp.cpp:276-300` (the `H` exporter). The
exporter's packing rule is the root cause of every GCC layout hazard below — it emits `GCC_PACK(4)` only on
the first bool of a bool run and on the first non-bool after a run, **within one class**:
```cpp
// Source/Editor/Src/UnEdExp.cpp:289-296
if (It->IsA(UBoolProperty::StaticClass()))
{   if (LastIt == NULL || !LastIt->IsA(UBoolProperty::StaticClass()))
        Ar.Logf( TEXT(" GCC_PACK(%i)"), PROPERTY_ALIGNMENT );
} else {
    if (LastIt != NULL && LastIt->IsA(UBoolProperty::StaticClass()))
        Ar.Logf( TEXT(" GCC_PACK(%i)"), PROPERTY_ALIGNMENT );
}
```
`LastIt` restarts at NULL for every class, so a subclass whose first member is a `BYTE` never gets the
alignment that MSVC's "a bitfield run owns a whole DWORD" rule gives it for free.

**ACTION:** we do **not** recompile `Engine.u` (owner decision), so we do **not** regenerate this header either.
Treat it as frozen data; the only permitted hand edits are layout pads/alignments (§10.4), each with a comment
pointing here, exactly as the template did at `engine-ut99/Source/Engine/Inc/EngineClasses.h:1865-1886`.

## 11. The 2.32 layout guard and how to verify C++ class sizes against script sizes

### 11.1 Where the guard is in the template (quote)
It lives in **Core**, not Engine: `engine-ut99/Source/Core/Src/UnClass.cpp`. Recording (native constructor,
`:295-302`):
```cpp
{
	// Layout guard: record the native C++ sizeof (InSize) keyed by object pointer, so UStruct::Link can
	// compare it against the size derived from the LOADED .u property offsets and warn on any C++/script
	// disagreement. Plain globals (BSS) -> safe at the static-init time these native constructors run.
	extern UStruct* GLayoutStructs[]; extern INT GLayoutSizes[]; extern INT GLayoutCount;
	if( GLayoutCount < 4096 ) { GLayoutStructs[GLayoutCount]=this; GLayoutSizes[GLayoutCount]=InSize; GLayoutCount++; }
}
UStruct* GLayoutStructs[4096]; INT GLayoutSizes[4096]; INT GLayoutCount=0;
```
Checking (end of the `Props` branch of `UStruct::Link`, `:364-385`, right after `PropertiesSize = Align(PropertiesSize,4);`):
```cpp
		// Layout guard (ported from feat/v436-compat, where it was a GENERAL fix living on a
		// target-specific branch): a native class's C++ sizeof must equal the size derived from the
		// loaded .u property offsets. A mismatch means the class's own members — and any native
		// subclass's — are read from the wrong offsets.
		//
		// ⚠ IT IS NECESSARY BUT NOT SUFFICIENT, and step 2.32 is the proof: the ABrush/AMover keyframe
		// bug passed this check. C++ may place a derived class's members in the base's TAIL PADDING, so
		// sizeof(base) is unchanged while the derived member moves, and AMover re-aligned before its end
		// so its size matched too. Only a per-PROPERTY offset comparison sees that class of bug.
		{
			extern UStruct* GLayoutStructs[]; extern INT GLayoutSizes[]; extern INT GLayoutCount;
			for( INT li=0; li<GLayoutCount; li++ )
				if( GLayoutStructs[li]==this )
				{
					if( GLayoutSizes[li] != PropertiesSize )
						debugf( NAME_Warning, TEXT("[layout] native %s: C++ sizeof=%i but script layout=%i -- member-offset shift risk"),
							GetName(), GLayoutSizes[li], PropertiesSize );
					break;
				}
		}
```

defines `IMPLEMENT_CLASS` (`Core/Inc/UnObjBas.h:348-367` MSVC and `:368-385` GCC-DLL use `EC_NativeConstructor`;

```python
# template-engine analyst: minimal UE1 (v61-79) package reader
import struct,sys,os
RF_HasStack=0x02000000
CPF_Net=0x20
class Pkg:
    def __init__(s,path):
        s.path=path; s.name=os.path.splitext(os.path.basename(path))[0]
        d=s.d=open(path,'rb').read()
        tag,ver,flags,nc,no,ec,eo,ic,io=struct.unpack_from('<9I',d,0)
        assert tag==0x9E2A83C1
        s.ver=ver&0xffff; s.lic=ver>>16
        s.names=[]; p=no
        for i in range(nc):
            if s.ver>=64:
                n,p=s.ci(p); st=d[p:p+n-1].decode('latin-1'); p+=n; p+=4
            else:
                e=d.index(b'\0',p); st=d[p:e].decode('latin-1'); p=e+1+4
            s.names.append(st)
        s.imports=[]; p=io
        for i in range(ic):
            cp,p=s.ci(p); cn,p=s.ci(p); pk=struct.unpack_from('<i',d,p)[0]; p+=4; on,p=s.ci(p)
            s.imports.append(dict(cpkg=s.names[cp],cls=s.names[cn],outer=pk,name=s.names[on]))
        s.exports=[]; p=eo
        for i in range(ec):
            c,p=s.ci(p); su,p=s.ci(p); pk=struct.unpack_from('<i',d,p)[0]; p+=4; on,p=s.ci(p)
            fl=struct.unpack_from('<I',d,p)[0]; p+=4; sz,p=s.ci(p); off=0
            if sz: off,p=s.ci(p)
            s.exports.append(dict(clsref=c,superref=su,outer=pk,name=s.names[on],flags=fl,size=sz,off=off,idx=i))
    def ci(s,p):
        d=s.d; b=d[p]; p+=1; neg=b&0x80; v=b&0x3f
        if b&0x40:
            sh=6
            while True:
                b=d[p]; p+=1; v|=(b&0x7f)<<sh; sh+=7
                if not b&0x80: break
        return (-v if neg else v),p
    def refname(s,r):
        if r==0: return None
        if r>0: return s.exports[r-1]['name']
        return s.imports[-r-1]['name']
    def clsname(s,e):
        return s.refname(e['clsref']) or 'Class'
    def fieldhdr(s,e,isclass):
        p=e['off']
        if e['flags']&RF_HasStack:
            node,p=s.ci(p); sn,p=s.ci(p); p+=8; p+=4
            if node: _,p=s.ci(p)
        if not isclass:
            t,p=s.ci(p)
            assert s.names[t]=='None',(e['name'],s.names[t])
        sup,p=s.ci(p); nxt,p=s.ci(p)
```

### `layout.py`
```python
# template-engine analyst: emulate HP2 433 UStruct::Link (PC rules) over loaded packages
import sys,struct,os
sys.path.insert(0,os.path.dirname(os.path.abspath(__file__)) if '__file__' in dir() else '.')
from upkg import Pkg,CPF_Net
PROPS={'ByteProperty','IntProperty','BoolProperty','FloatProperty','ObjectProperty','ClassProperty','NameProperty','StrProperty','StringProperty','FixedArrayProperty','ArrayProperty','MapProperty','StructProperty'}
STRUCTY={'Class','Struct','State','Function'}
def load(paths):
    global pkgs,byname
    pkgs=[Pkg(p) for p in paths]; byname={}
    for pk in pkgs:
        for e in pk.exports:
            e['pkg']=pk; e['cls']=pk.clsname(e)
            if e['cls'] in ('Class','Struct'): byname.setdefault(e['name'],e)
def resolve(pk,r):
    if r==0: return None
    if r>0: return pk.exports[r-1]
    im=pk.imports[-r-1]
    return byname.get(im['name']) if im['cls'] in ('Class','Struct') else None
def parse_field(e):
    if 'parsed' in e: return
    pk=e['pkg']; c=e['cls']
    sup,nxt,p=pk.fieldhdr(e, c=='Class')
    e['next']=nxt
    if c in STRUCTY:
        st,p=pk.ci(p); ch,p=pk.ci(p); e['children']=ch
    if c in PROPS:
        dim,fl=struct.unpack_from('<iI',pk.d,p); p+=8; cat,p=pk.ci(p)
        if fl&CPF_Net: p+=2
        e['dim']=dim; e['pflags']=fl
        if c=='ByteProperty': e['enum'],p=pk.ci(p)
        elif c=='ObjectProperty': e['pclass'],p=pk.ci(p)
        elif c=='ClassProperty': e['pclass'],p=pk.ci(p); e['meta'],p=pk.ci(p)
        elif c=='StructProperty': e['struct'],p=pk.ci(p)
        elif c=='FixedArrayProperty': e['inner'],p=pk.ci(p); e['count']=struct.unpack_from('<i',pk.d,p)[0]; p+=4
        elif c=='ArrayProperty': e['inner'],p=pk.ci(p)
        elif c=='MapProperty': e['key'],p=pk.ci(p); e['value'],p=pk.ci(p)
        elif c=='StringProperty': e['strsize']=struct.unpack_from('<i',pk.d,p)[0]; p+=4
    e['parsed']=1
SIZE={}; LAYOUT={}
def elem(e):
    c=e['cls']
    if c=='ByteProperty': return 1,1
    if c in('IntProperty','FloatProperty','ObjectProperty','ClassProperty','NameProperty','BoolProperty'): return 4,4
    if c in('StrProperty','ArrayProperty'): return 12,4
    if c=='MapProperty': return 20,4
    if c=='StringProperty': return e['strsize'],4
    if c=='StructProperty':
        sz=props_size(resolve(e['pkg'],e['struct'])); return sz,(2 if sz==2 else 4 if sz>=4 else 1)
    if c=='FixedArrayProperty':
        inn=resolve(e['pkg'],e['inner']); parse_field(inn); es,_=elem(inn); return es*e['count'],4
    raise Exception('unknown prop '+c)
def align(x,a): return (x+a-1)//a*a
def props_size(st):
    key=(st['pkg'].name,st['idx'])
    if key in SIZE: return SIZE[key]
    parse_field(st); size=0
    if st['superref']:
        size=props_size(resolve(st['pkg'],st['superref']))
    lay=[]; prevbool=None; bit=0; r=st['children']
    while r>0:
        f=st['pkg'].exports[r-1]
        if f['outer']!=st['idx']+1: break
        parse_field(f)
        if f['cls'] in PROPS:
            es,al=elem(f)
            if f['cls']=='BoolProperty' and prevbool is not None and st['cls']!='Function' and bit<31:
                off=prevbool['offset']; bit+=1
            else:
                off=align(size,al); bit=0
            f['offset']=off; size=off+es*f['dim']
            prevbool=f if f['cls']=='BoolProperty' else None
            lay.append((f['name'],f['cls'],off,es*f['dim'],f['dim']))
        r=f['next']
    size=align(size,4); SIZE[key]=size; LAYOUT[key]=lay
    return size
```

```python
# template-engine analyst: EngineClasses.h data-member parser
import re
MEM=re.compile(r'^(class\s+\w+\s*\*|struct\s+\w+\s*\*|\w+(?:<[^>]*>)?\s*\*?)\s*(\w+)(\[(\w+)\])?(\s*:\s*\d+)?$')
def parse_header(path):
    h=open(path,encoding='latin-1').read().split('\n')
    classes={}; order=[]; i=0
    while i<len(h):
        m=re.match(r'\s*class\s+(?:ENGINE_API\s+|CORE_API\s+)?(\w+)\s*:\s*public\s+(\w+)\s*$',h[i])
        if m:
            name,sup=m.group(1),m.group(2); mem=[]; j=i+1
            while j<len(h):
                t=h[j].strip()
                if 'DECLARE_CLASS' in t or t.startswith('};'): break
                if not t or t in('{','public:') or t.startswith('//') or t.startswith('#'): j+=1; continue
                raw=t; pk='GCC_PACK' in raw; al='GCC_ALIGN' in raw
                t2=re.sub(r'GCC_PACK\(\d\)|GCC_ALIGN\(\d\)','',t).strip()
                if t2.endswith(';') and '(' not in t2:
                    mm=MEM.match(t2[:-1].strip())
                    if mm:
                        ty=re.sub(r'\s+','',mm.group(1)) if '*' in mm.group(1) else mm.group(1).strip()
                        mem.append(dict(line=j+1,type=ty,name=mm.group(2),dim=mm.group(4),bits=mm.group(5),pack=pk,align=al,raw=raw))
                        j+=1; continue
                break
            while j<len(h) and 'DECLARE_CLASS' not in h[j]: j+=1
            classes[name]=dict(sup=sup,mem=mem,line=i+1)
            order.append(name); i=j
        i+=1
    return classes,order
```

### `model.py`
```python
# template-engine analyst: C++ layout models. 'gcc' = SysV i386 / wasm32 clang (GCC_PACK'd lone bitfield
# runs occupy ceil(bits/8) bytes; derived members may use the base's tail padding). 'msvc' = Win32 /Zp4 and
# MinGW -mms-bitfields (bitfield runs occupy whole DWORDs; derived class starts at sizeof(base)).
import math
BASIC={'BYTE':(1,1),'INT':(4,4),'FLOAT':(4,4),'DWORD':(4,4),'FName':(4,4),'FStringNoInit':(12,4),'FString':(12,4),'UBOOL':(4,4),'BITFIELD':(4,4),'FColor':(4,4),'SWORD':(2,2),'_WORD':(2,2),'float':(4,4),'int':(4,4),'FTime':(8,4),'DOUBLE':(8,4),'QWORD':(8,4),'SQWORD':(8,4),'FVector':(12,4),'FRotator':(12,4),'FPlane':(16,4),'FCoords':(48,4)}
def msize(ty,structsize):
    if ty.endswith('*'): return 4,4
    if ty.startswith('TArray'): return 12,4
    if ty in BASIC: return BASIC[ty]
    s=structsize(ty)
    return s,(4 if s>=4 else s)
def place(members,start,model,structsize):
    off=start; offs={}; bp=None
    for m in members:
        if m['bits']:
            if bp is None or m['pack'] or bp[1]>=32: bp=[(off+3)//4*4,0]
            offs[m['name']]=bp[0]; bp[1]+=1
            off=bp[0]+(math.ceil(bp[1]/8) if model=='gcc' else 4); continue
        bp=None
        sz,al=msize(m['type'],structsize)
        if m['pack'] or m['align']: al=max(al,4)
        off=(off+al-1)//al*al; offs[m['name']]=off
        d=int(m['dim']) if m['dim'] else 1
        off+=sz*d
    return off,offs
```
